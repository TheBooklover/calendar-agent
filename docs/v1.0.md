# V1.0 – AI-Augmented Deterministic Planner

## Objective

Demonstrate safe integration of LLM reasoning into a deterministic planning engine without compromising correctness.

---

## Deterministic Core

`propose_blocks()` remains the source of truth.

Properties:
- Slot-aware greedy scheduling
- Deterministic ordering
- Explicit buffer handling
- Minimum block enforcement

---

## AI Integration Model

AI does NOT generate final plans.

Instead:

1. AI returns a structured `AIPlanningProposal`
2. Proposal is validated
3. Proposal is bounded and applied
4. Deterministic fallback is always available

---

## AI Contract

AI returns:

- goal reordering
- buffer suggestions
- soft adjustments

It does NOT:
- generate raw time blocks
- override deterministic rules
- directly write to calendar

---

## Validator Guardrails

All proposals pass through:

`validate_ai_planning_proposal(proposal, goal_labels)`

Validator ensures:

- Only known goals are referenced
- No invalid duraons
- No unsafe modifications

All validator outputs are normalized to `List[str]`.

---

## Orchestrator Strategy

`plan_with_optional_ai()`:

1. Generate baseline
2. Attempt AI proposal (if enabled)
3. Validate proposal
4. Apply bounded changes
5. Return `PlanResult`

If ANY step fails:
→ Fallback to deterministic baseline.

---

## Explainability Model

`PlanResult` includes:

- baseline_blocks
- final_blocks
- ai_attempted
- ai_used
- ai_error
- ai_validation_errors

This enables:
- Observability
- Debugging
- Trust transparency
